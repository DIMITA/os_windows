# WilOS Aurora — Roadmap

WilOS is a Linux distribution. The roadmap is therefore about what
we add **on top of** Arch + Linux, not about reinventing kernels.

## v0.1 — "Aurora seed" (this commit)

- [x] archiso profile that produces a bootable BIOS+UEFI live ISO
- [x] Hyprland compositor with Aurora glass (blur, rounded corners,
      ambient shadows, spring animations, gestures)
- [x] Top Waybar (macOS-style menu bar) + bottom Waybar dock
- [x] wofi launcher (Spotlight-like)
- [x] mako notifications themed in the Aurora palette
- [x] Kitty terminal themed in the Aurora palette
- [x] greetd + tuigreet login with WilOS branding
- [x] `wilos-install` text installer with typed `WIPE <disk>` gate,
      Btrfs subvolumes (`@ @home @log @cache @snapshots`),
      systemd-boot setup
- [x] `flash-usb.sh` helper that refuses to overwrite internal disks
- [x] Procedural Aurora wallpaper generated by `make-wallpaper.sh`

## v0.2 — Polish + first-party identity (this commit)

- [x] WilOS aurora glyph (SVG) used as branding everywhere — boot
      splash, login, dock launcher, About panel, fastfetch
- [x] GTK4 / libadwaita Aurora overrides (gtk.css + settings.ini)
      retinting Files, Settings, Calculator, Photos, Text Editor
- [x] GTK3 fallback for legacy apps (nm-connection-editor, blueman,
      pavucontrol)
- [x] Plymouth boot splash theme `wilos` with breathing logo and
      LUKS password prompt support
- [x] Window controls on the LEFT (macOS-leaning) via gtk-decoration
      -layout
- [x] Papirus-Dark icon theme + Adwaita cursor wired in via gsettings
      on first run
- [x] Graphical installer (`wilos-installer`, GTK4 + libadwaita) with
      a 7-page wizard (Welcome → Disk → User → Locale → Confirm →
      Progress → Done) talking to the same `wilos-install` backend
      via `--config FILE`
- [x] PolicyKit policy that lets the GUI elevate via pkexec
- [x] Desktop entry + dock button for the installer

## v0.3 — Polish round 2 (this commit)

- [x] First-party Aurora icon set (`wilos-aurora`) overlaying
      Papirus-Dark with custom Files / Terminal / Browser / Settings
      / Installer / Tour / Time Machine glyphs and an `index.theme`
- [x] First-run welcome tour (`wilos-tour`) — Adw.Carousel with 7
      slides covering Spotlight, dock, workspaces, terminal, install
- [x] User account avatar selection during install — 6 preset
      glyphs + "None", written to AccountsService for the lock screen
- [x] System sound design — notification ding + login arpeggio +
      logout arpeggio + error tone, synthesised by `make-sounds.sh`
      (sox + oggenc), wired into mako and the firstrun login chime
- [x] Snapper config (`/`), pre/post pacman hooks, timeline +
      cleanup timers enabled by the installer
- [x] `wilos-timemachine` — GTK4 + libadwaita snapshot browser with
      one-click rollback (typed-confirmation modal, safety snapshot
      taken first), exposed in the dock with a custom icon
- [x] `wilbar` — Rust + GTK4 + gtk4-layer-shell scaffold for the
      future native top bar (clock-only v0; Waybar still ships)

## v0.4 — Compositor split + ecosystem (this commit)

- [x] **Wilcenter** (`wilcenter`, GTK4 + libadwaita) — KRunner-style
      command palette with provider model: calc, unit conversion
      (length/mass/volume/temperature), clipboard history, file
      finder ($HOME), .desktop launcher, web search, system actions
      (lock/logout/reboot/shutdown). Bound to **Super + /**.
- [x] **Snap layouts** (`wilos-snap`, GTK4) — fullscreen glass
      chooser with 6 presets (Fullscreen / 50-50 split / Main+stack
      / Thirds / Sidebar-left / Sidebar-right). Picks rearrange the
      focused workspace via `hyprctl` move/resize. Bound to
      **Super + Shift + S**.
- [x] **Wildock** (Rust crate) — native bottom dock anchored via
      gtk4-layer-shell, reads `/etc/wilos/dock.toml` for pinned
      items, hover-lift animation. Pinned-only in this revision;
      taskbar (foreign-toplevel-management) lands in v0.5.
- [x] **Wilbar** modules — workspaces (Hyprland IPC over the events
      socket), focused window title, audio (`wpctl`), battery
      (`/sys/class/power_supply`), brightness
      (`/sys/class/backlight`), network (`nmcli`), clock. Tray
      (StatusNotifierItem) and taskbar still scaffold-only.
- [x] **Notes** (`wilos-notes`, GTK4 + libadwaita) — first-party
      markdown editor with autosave (600 ms debounce), filename
      derived from first heading, search box, `~/Notes/` storage.
      Bound to **Super + M**.
- [x] **Calendar / Mail / Camera** — first-party desktop entries
      with custom Aurora icons fronting GNOME Calendar / Geary /
      GNOME Snapshot, so the app drawer shows "Calendar" / "Mail"
      / "Camera" with our visual identity.
- [x] Keybinds wired in `hyprland.conf`: Super+Space (Launchpad),
      Super+/ (Wilcenter), Super+Shift+S (Snap layouts),
      Super+M (Notes), Super+Ctrl+S (screenshot region).

## v0.3 — Productivity layer

- [ ] Polished window snap layouts (FancyZones-equivalent)

## v0.4 — Apps and ecosystem

- [ ] **WilStore**: friendly front-end over Pacman + Flatpak with
      verified-publisher badges
- [ ] First-party Mail, Calendar, Notes, Camera, Music apps
      (libadwaita)
- [ ] Curated app catalogue with WilOS-styled screenshots
- [ ] Snapper-based time-machine restore UI on `@snapshots`

## v0.5 — Cross-device

- [ ] WilSync: browser, files, settings sync across WilOS machines
- [ ] WilLink: Android / iOS pairing (notifications, calls, files)
- [ ] WilCast: stream desktop + audio to TVs (Miracast / DLNA)
- [ ] Continuity-style handoff between WilOS devices

## v1.0 — General availability

- [ ] LTS release branch with curated package set

- [ ] Documentation site
- [ ] Public bug tracker

## Long-term — feature parity tracking

These mirror modern Windows / macOS surfaces so WilOS users get the
same baseline experience:

- [ ] AI command palette / writing assistant (local model first,
      opt-in cloud second)
- [ ] HDR + auto-HDR pipeline once Hyprland exposes it
- [ ] Hardware-rooted security (TPM, secure boot, signed updates)
- [ ] Tabbed shell across Files, Terminal, Settings, Notes
- [ ] Cloud-stream a remote WilOS session to any device
- [ ] Native ARM64 build with x86_64 translation (box64-equivalent)
- [ ] Optional Windows app compatibility via Wine + DXVK shipped
      from the store, sandboxed
