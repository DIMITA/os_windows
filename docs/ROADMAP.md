# WilOS Aurora — Roadmap

WilOS is a Linux distribution. The roadmap is therefore about what
we add **on top of** Arch + Linux, not about reinventing kernels.

## v0.1 — "Aurora seed" (this commit)

- [x] archiso profile that produces a bootable BIOS+UEFI live ISO
- [x] Hyprland compositor with Aurora glass (blur, rounded corners,
      ambient shadows, spring animations, gestures)
- [x] Top Waybar (macOS-style menu bar) + bottom Waybar dock
- [x] wofi launcher (Spotlight-like)
- [x] mako notifications themed in the Aurora palette
- [x] Kitty terminal themed in the Aurora palette
- [x] greetd + tuigreet login with WilOS branding
- [x] `wilos-install` text installer with typed `WIPE <disk>` gate,
      Btrfs subvolumes (`@ @home @log @cache @snapshots`),
      systemd-boot setup
- [x] `flash-usb.sh` helper that refuses to overwrite internal disks
- [x] Procedural Aurora wallpaper generated by `make-wallpaper.sh`

## v0.2 — Polish + first-party identity

- [ ] Custom GTK4 / libadwaita theme matching Aurora exactly
- [ ] Custom icon set (rounded outline, two-tone)
- [ ] Custom cursor pack
- [ ] System sound design (notification, login chime)
- [ ] Replace text installer with a graphical Hyprland-hosted version
      sharing the same backend script
- [ ] First-party app skin pass on Nautilus, Settings, Calculator,
      Photos
- [ ] WilOS branding everywhere: Plymouth boot splash, login,
      About panel
- [ ] User account avatar selection during install

## v0.3 — Productivity layer

- [ ] **Wilbar** (rewrite of the top bar in Rust + GTK4 + libadwaita)
      with a first-class control centre dropdown
- [ ] **Wildock** (rewrite of the dock with magnification animation,
      pinned-app management, badges)
- [ ] **Wilcenter**: KRunner-style command palette with calc, units,
      web search, quick file open, clipboard history
- [ ] System-wide screenshot / screen recording flow
- [ ] Polished window snap layouts (FancyZones-equivalent)
- [ ] Workspace overview gesture (3-finger swipe up)

## v0.4 — Apps and ecosystem

- [ ] **WilStore**: friendly front-end over Pacman + Flatpak with
      verified-publisher badges
- [ ] First-party Mail, Calendar, Notes, Camera, Music apps
      (libadwaita)
- [ ] Curated app catalogue with WilOS-styled screenshots
- [ ] Snapper-based time-machine restore UI on `@snapshots`

## v0.5 — Cross-device

- [ ] WilSync: browser, files, settings sync across WilOS machines
- [ ] WilLink: Android / iOS pairing (notifications, calls, files)
- [ ] WilCast: stream desktop + audio to TVs (Miracast / DLNA)
- [ ] Continuity-style handoff between WilOS devices

## v1.0 — General availability

- [ ] LTS release branch with curated package set
- [ ] Signed update channel
- [ ] Full hardware lab test matrix (laptops, desktops, mini-PCs)
- [ ] Documentation site
- [ ] Public bug tracker

## Long-term — feature parity tracking

These mirror modern Windows / macOS surfaces so WilOS users get the
same baseline experience:

- [ ] AI command palette / writing assistant (local model first,
      opt-in cloud second)
- [ ] HDR + auto-HDR pipeline once Hyprland exposes it
- [ ] Hardware-rooted security (TPM, secure boot, signed updates)
- [ ] Tabbed shell across Files, Terminal, Settings, Notes
- [ ] Cloud-stream a remote WilOS session to any device
- [ ] Native ARM64 build with x86_64 translation (box64-equivalent)
- [ ] Optional Windows app compatibility via Wine + DXVK shipped
      from the store, sandboxed
